# media

`larp`, typed at any prompt in the studio, plays the video published here.

Name it **`larp.mp4`** (or `larp.webm` / `larp.mov`) and drop it in this
folder. The page lists all three as sources and the browser takes the first
one it can decode, so the extension does not have to match exactly.

MP4 (H.264 + AAC) is the safe choice — it plays in every browser. WebM is
fine in Chrome and Firefox but not reliably in Safari.

Keep it under 100 MB: GitHub refuses larger files, and the whole published
site has about 1 GB to work with.
